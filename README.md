# 秒视 AI · 漫剧分镜生成器

> 把一段小说，自动拆解成能直接出片的漫剧分镜提示词。
> 纯前端单文件工具，**只产提示词，不替你生成图片**——提示词拿去即梦 / 可灵 / Seedance 出图、出视频。

在线版本：`https://4kmrtmkh3esnq.doubao.link/app/app_17g7mundaqu`

---

## 一、它是干什么的

面向漫剧 / AI 短视频创作者的分镜工作台。你从任意小说平台（番茄、红果、七猫等）复制一段小说，它会：

1. **智能剔水**：删掉没画面、没冲突的"水镜"，只留推动剧情的有效镜头。
2. **提炼看点**：总结这段内容最该留下的反转、冲突、情绪高光。
3. **逐镜分镜**：拆成一条一条镜头，每镜给出节拍、景别、运镜、时长、台词。
4. **双轨提示词**：每镜同时产出
   - **出图提示词**（静帧图，粘到即梦/可灵「文生图」）
   - **视频提示词**（图生视频，先传静帧，再粘到「图生视频」）
5. **可视化画布**：脚本 → 出图提示词 → 视频提示词 三列节点管道，可拖拽、可分支对比、一键复制。

两种生成模式：

- **本地规则模式（免费用）**：不填任何 Key，内置 NLP 规则引擎，离线就能跑，秒出。
- **AI 增强模式（可选）**：填一个 DeepSeek（或任意 OpenAI 兼容接口）的 Token，由大模型生成更细腻的分镜。

## 二、快速开始

### 方式 A：直接打开（最简单）

双击 `index.html`，用 Chrome / Edge 浏览器打开即可，**无需安装任何东西、无需联网**（本地规则模式）。

### 方式 B：用 AI 增强模式

1. 打开页面后，点右上角「**API 设置**」。
2. 只填一项「**Token**」：粘贴你的 DeepSeek API Key（`sk-` 开头）。
   - API 地址留空会自动用 `https://api.deepseek.com/chat/completions`
   - 模型留空默认 `deepseek-chat`
   - Token 只保存在你当前浏览器的本地存储里，不上报给任何第三方。
3. 回到工作台，在右侧贴小说，点「调用 AI 生成分镜」。

### 操作流程

1. 首页点「开始免费生成」进入工作台（左侧 3/4 画布、右侧 1/4 输入与设置）。
2. 右侧文本框粘贴小说，选风格 / 镜头数 / 画幅 / 单镜时长。
3. 点「生成分镜提示词」（本地）或「调用 AI 生成分镜」（AI）。
4. 在画布或「脚本 / 看点 / 提示词 / 对白 / 发布 / 镜头」标签页查看结果。
5. 逐镜复制提示词：先出图、再图生视频，拼成漫剧。

## 四、技术栈

- **原生 HTML / CSS / JavaScript**，零框架、零构建、零外部依赖（不依赖任何外网 JS/CSS 库）。
- 画布用 **DOM 节点 + SVG 连线 + 自研平移/缩放引擎**实现。
- 数据在浏览器内存中流转，可选手动填 Token 直连大模型 API。
- 暗色电影感视觉，动效遵循专业动效规范（强 ease-out、≤300ms、尊重系统"减少动态效果"）。

---

## 五、隐私说明

- 不填 Token：所有解析在你浏览器本地完成，小说内容**不离开你的设备**。
- 填了 Token：小说与提示词会按你填写的地址直接发送给对应大模型服务商（默认 DeepSeek），用于生成分镜。Token 仅存在浏览器本地存储中。
- 本工具本身不收集、不上传任何内容。

- 支持手机浏览器打开，但画布的拖拽体验在桌面端最佳。
